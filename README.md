# TerangaPay

## Présentation
TerangaPay est un projet pédagogique d'industrialisation et d'automatisation
de l'infrastructure et du déploiement d'une application de paiement simulée.

## Objectifs
- Provisionner l'infrastructure avec OpenTofu.
- Déployer et configurer les services avec Ansible.
- Conteneuriser les services avec Docker.
- Automatiser les opérations avec un Makefile.
- Sécuriser la gestion des secrets.
- Mettre en place des contrôles et des tests.

## Environnement technique
- Ubuntu sous WSL2
- Docker
- OpenTofu
- Ansible
- Git

## Statut
Projet en cours de réalisation dans le cadre du cours
Automatisation et Gestion de Configuration.
